# 🪢 Raksha Bandhan Greeting Website

Celebrate the beautiful bond between brothers and sisters with this festive, interactive Raksha Bandhan website! Built using HTML, CSS, JavaScript, and Bootstrap 5, it allows users to send greetings, create custom cards, view cherished memories, and enjoy animations, music, and more.

---

## 📁 Project Structure

Rakshabandhan/
├── index.html → Homepage with hero section, countdown, music, and festive buttons
├── about.html → About Raksha Bandhan (in Hindi & English)
├── greeting.html → Collection of short, emotional, and funny greetings
├── gallery.html → Brother-sister photo & GIF gallery
├── card-generator.html → Form to create personalized Rakhi cards
├── creator.html → Credits and portfolio link of the creator
│
├── css/
│ ├── style.css → Global styles and theme colors
│ ├── responsive.css → Responsive design rules
│ └── animation.css → Animations (flip, fade, festive effects)
│
├── js/
│ ├── main.js → Header/footer loader, scroll effects
│ ├── greetings.js → Load and display greetings from JSON
│ ├── card-generator.js → Dynamic greeting card builder
│ ├── countdown.js → Countdown to Raksha Bandhan
│ └── music.js → Background music toggle control
│
├── images/
│ ├── rakhi.jpg → Hero image
│ ├── siblings/ → Childhood and modern photos
│ └── gifs/ → Rakhi animation GIFs
│
├── audio/
│ └── bg_music.mp3 → Soothing Raksha Bandhan background music
│
├── cards/
│ ├── classic.html → Sample classic greeting card
│ ├── funny.html → Sample funny card
│ └── modern.html → Sample modern design
│
├── components/
│ ├── header.html → Bootstrap navbar (included on every page)
│ └── footer.html → Footer with social links and credits
│
├── data/

├── .gitignore

## ✨ Features

- 🎨 **Beautiful UI** – Glassmorphism, hover effects, and 3D card animations
- 💌 **Greeting Library** – Scroll through various Rakhi wishes
- 🧧 **Custom Card Generator** – Input your own message, preview, and download/share
- 👫 **Memory Gallery** – Childhood to adulthood photo memories
- 🔊 **Music & Countdown** – Festive audio with a toggle and timer until Rakhi day
- 🌐 **Multilingual** – Includes Hindi + English content (manual toggle)
- 📱 **Responsive Design** – Mobile-first, works on all screen sizes
- 🧩 **Modular Components** – Header/footer reused across pages

---

## 🚀 Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Bootstrap 5
- GSAP / AOS for animations
- LottieFiles for animated icons (optional)
- Swiper.js (optional for carousel)
- Typed.js for typewriter effects
